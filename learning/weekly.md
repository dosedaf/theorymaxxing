# Weekly structure

- **6 days on, 1 light day.**
- **Every day** produces two artifacts automatically: a brain dump and a build
  dump. They accumulate in `dumps/` and feed `gap-list.md`.

## Sunday ritual (light day)

1. **Re-dump (20 min):** last week's 3 biggest ideas, from memory, no notes.
2. Check against `gap-list.md` → what you missed becomes next week's
   Block 1 warm-up.
3. Plan the week: pick the **three weekly goals** (below).
4. Edit + publish the blog post if one is due. Publish at 90%.

## Weekly goals: exactly three

| # | Type | Verifiable by |
|---|---|---|
| 1 | Learning target | A dump file that proves understanding |
| 2 | Build target | A pipeline/repo state |
| 3 | Writing target | A draft or published post |

Each goal must be verifiable by an **artifact, not effort**. "Studied Kafka"
is not a goal. "Dump file explains consumer group rebalancing without
peeking" is.

Three targets done = good week, regardless of hours.

## Mid-week check (5 min, daily if needed)

- Is Block 2 stuck on the same bug for >1 day?
- → Move it to light hours with AI assist. A stuck bug must never eat Block 1.
